# Interactive Profile Card 

## Cara Menjalankan Local Server
Untuk memastikan fitur Fetch API berjalan normal tanpa error CORS, file ini harus dijalankan melalui *local server*. 

**Langkah-langkah di VS Code:**
1. Buka folder proyek ini di dalam Visual Studio Code.
2. Gunakan compiler, dimana disini saya menggunakan ekstensi **Live Server** .
3. Buka file `index.html`.
4. Klik tombol **"Go Live"** di bagian kanan bawah layar VS Code, atau klik kanan pada kode `index.html` lalu pilih **"Open with Live Server"**.
5. Browser akan terbuka otomatis mengarah ke alamat lokal seperti `http://127.0.0.1:5500`.
